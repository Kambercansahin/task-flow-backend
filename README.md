# TaskFlow API

TaskFlow, kullanıcıların projeler oluşturabildiği, görevlerini yönetebildiği ve ilerlemelerini takip edebildiği bir REST API projesidir.

## Özellikler

* Kullanıcı kaydı ve giriş yapma
* Proje oluşturma ve yönetme
* Görev oluşturma, güncelleme ve silme
* Görev durumlarını ve önceliklerini takip etme
* Görevleri filtreleme, sıralama ve sayfalama
* Kullanıcı kimlik doğrulama ve yetkilendirme
* Otomatik testler ve hata yönetimi
* AI destekli görev önerileri

## Teknolojiler

Python, FastAPI, PostgreSQL, SQLAlchemy, Alembic, Pytest ve Docker.

## Geliştirme Süreci

Proje; veritabanı tasarımı, API geliştirme, kimlik doğrulama, test ve dağıtım aşamalarından geçerek adım adım geliştirilecektir. AI özellikleri, temel backend yapısı tamamlandıktan sonra eklenecektir.
